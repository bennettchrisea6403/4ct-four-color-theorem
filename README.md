## About the Project

4CT brings the Four Color Theorem into an interactive browser setting. Instead of presenting the theorem solely as an abstract mathematical result, it lets users visually inspect the operation of a four-coloring algorithm and observe how planar graphs behave during the process.

The tool is intended for students, teachers, graph theory enthusiasts, and anyone exploring planar graphs, topology, or constructive mathematics. It also investigates topology changes as a route toward an optimized three-color representation of a planar graph.

---

## What 4CT Demonstrates

- A constructive approach to the Four Color Theorem.
- Graph coloring principles through a browser-based interface.
- Planar graph structures together with their associated color assignments.
- An interactive algorithm for four-coloring.
- The role of topology modification in three-color optimization.
- Step-by-step visual experimentation connecting graph theory and topology.
- A hands-on way to examine how coloring results develop during the demonstration.

You can explore the demonstration by following this sequence:

2. Inspect the planar graph shown by the application.
